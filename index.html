ClaudeTTY

A Mac terminal for running as much Claude Code as you'll ever need.

macOS 26 or later, Apple Silicon.
Free, and the source is on GitHub.

I made this because I let Claude write the code and only step in to make an edit now and then. You don't really need file trees or editors for that, so I took them out. Edits I'd make feel kind of worthless anyways, since Claude replaces them eventually.

I was using cmux before this. It's a good app, but it was buggy for me (crashed a lot, updates killed everything, and it'd pile up a bajillion unread notifications that didn't work properly). ClaudeTTY keeps the layout I liked, groups in a sidebar and tabs in the titlebar, and gets rid of the bloat. Every tab runs in the background so updates and crashes are headache-free.

looks

See what every Claude is doing. Each tab's dots move differently for thinking, writing, reading, searching and running code, or switch to Clawd and he acts it all out. A tab waiting on you turns amber.

ct

ClaudeTTY installs a Claude Code plugin and a ct command, so the Claude in one tab can open, watch and steer the others.

ct list                          # every tab, its group, folder and Claude state
ct web dev bun run dev           # open tab "dev" in group "web", running a command
ct split dev right agent claude  # a new pane beside it with Claude in it
ct wait agent idle               # block until that Claude is done
zmx send agent "run the tests"   # type into it

Don't even look at this, it's for your Claude. ClaudeTTY teaches it to Claude automatically in ~75 tokens.

install

Download ClaudeTTY.dmg, open it and drag ClaudeTTY to Applications. It updates itself after that.

On your phone or tablet, just use the Claude app. It's pretty good.
